# Projeto-Zoop-Analytics
Solução de Analytics ponta a ponta para a fintech Zoop. Inclui engenharia e qualidade de dados com Python, modelagem Star Schema e cálculo de métricas canônicas de negócio em DAX no Power BI. Conta com um painel executivo para análise de performance comercial e um painel de diagnóstico para mitigação de fraudes e chargebacks.
